# pm-config.json schema

File at `.claude/pm-config.json` in the target project. Generated by `/pm:setup-project`.

## Full structure

```json
{
  "owner": "org-or-user",
  "repo": "repo-name",
  "project_number": 1,
  "project_id": "PVT_...",
  "status_field_id": "PVTSSF_...",
  "status_options": {
    "Triage":      "a1b2c3d4",
    "Backlog":     "e5f6a7b8",
    "Todo":        "1a2b3c4d",
    "Ready":       "5e6f7a8b",
    "In Progress": "9c8d7e6f",
    "In Review":   "2b3a4c5d",
    "Blocked":     "6f5e4d3c",
    "Done":        "d4c3b2a1"
  }
}
```

`project_id` and `status_field_id` are GraphQL node IDs (`PVT_...` / `PVTSSF_...`
prefixes). **Single-select option IDs are a different shape** — short 8-character hex
strings with no prefix (e.g. `fa8b43b7`), not `PVTSSFO_...` node IDs. Get them from the
`options { id name }` field in the setup query (`/pm:setup-project` does this for you).

## How to use the IDs in GraphQL mutations

```bash
# Move item to "In Progress":
ITEM_ID=$(gh api graphql -f query='
  query($proj: ID!, $after: String) {
    node(id: $proj) {
      ... on ProjectV2 {
        items(first: 100, after: $after) {
          nodes { id content { ... on Issue { number } } }
        }
      }
    }
  }' -F proj="<project_id>" --jq ".data.node.items.nodes[] | select(.content.number == <N>) | .id")

gh api graphql -f query='mutation {
  updateProjectV2ItemFieldValue(input: {
    projectId: "<project_id>"
    itemId: "'"$ITEM_ID"'"
    fieldId: "<status_field_id>"
    value: { singleSelectOptionId: "<In Progress ID from status_options>" }
  }) { projectV2Item { id } }
}'
```

## Add issue to the project

```bash
ISSUE_URL=$(gh issue view <N> --json url --jq .url --repo <owner>/<repo>)
gh project item-add <project_number> --owner <owner> --url "$ISSUE_URL"
```
